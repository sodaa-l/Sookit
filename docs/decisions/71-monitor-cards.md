# 71 · 直播监控列表使用封面卡片

日期：2026-11-06

## 背景与选择

监控列表原先用表格展示标题、链接和状态。参考封面在上、信息与操作在下的卡片结构，视觉以“任务队列 / 已完成”卡片为基准，沿用 Sookit 的主题、字体和按钮，不引入参考图中的固定深色背景。用户明确要求信息区保持舒展，并在查看效果后确认采用无外框平铺：去掉独立底板、边框和卡片悬停效果，条目之间用留白分隔。

## 布局

- `MonitorCard` 使用透明的普通 `QWidget` 容器，不绘制底板、外框或悬停效果；复用 `RoundedCoverWidget` 的 8px 圆角，封面随条目宽度保持 16:9，外边距 6px。
- 标题使用微软雅黑 12pt 粗体与两行省略标签；频道、时间和状态使用 10pt，全文通过 tooltip 查看。信息区至少 180px，并根据实际字体和行数扩展。
- `ScrollArea + AdaptiveFlowLayout` 自适应列数，卡宽 320–640px；水平间距 16px、垂直间距 24px，右侧固定留白 24px。
- 常驻 `QStackedWidget` 展示槽切换空态与列表，承接剩余空间，避免添加/移除任务推动上方输入区。

## 交互及状态

观看通过默认浏览器打开原视频；等待开播时显示“立即开始”；下载中“删除”变为“取消”，完成及等待重试恢复“删除”。保留轮询、自动下载、重试、目录联动及完成后保存封面的原有流程。

所有操作与状态更新按 `task_id` 定位卡片，禁止依赖表格行号。删除后迟到的初始嗅探及下载就绪信号不得复活任务。等待定时器统一调用当前任务信息，保存目录改动后仍使用最新目录。完成时清理队列映射，删除已完成的监控卡片不会取消队列历史。

## 异步与释放

显示封面与下载后保存封面互相独立。显示封面通过 YouTube ID 异步逐档回退，线程内只解码 `QImage`，GUI 槽中创建 `QPixmap`；回调检查当前 loader 身份与 dispose 状态。独立 loader 强引用持有到 `finished`，移除卡片时中断请求并断开回调，网络超时后退出，不阻塞 GUI。

初始嗅探改为按任务持有线程至 `finished`，避免频道批量添加时覆盖单一引用。页面退出停止等待和倒计时并 dispose 卡片，拒绝迟到结果。

## 验证与边界

新增监控页面回归覆盖删除后回调、等待开始读取最新目录、取消自身下载、完成后删除、失败自动重试、空态/滚动布局稳定及退出后等待回调。另以离屏文字/几何断言验证卡片尺寸、按钮信号、坏图回退及加载中删除；不生成截图。

封面获取失败展示“暂无封面”；初始信息未获得时频道和开播时间显示待获取/待定。窄窗口自动减少列数；信息区不通过压缩间距来强行容纳更多任务。

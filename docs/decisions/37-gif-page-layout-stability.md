# 决策 37. 动图页版式重构：解析前后零位移（2026-10-13）

> 决策索引：[DEVELOPMENT.md](../DEVELOPMENT.md#决策索引)（编号与代码注释里的「决策 37」一一对应）

背景：决策 30 接的动图页在真机上暴露三个版式问题——① 一进页面控件被撑得很开（大片空隙），
丢个链接解析成功后**整页往上顶**；② 「下载并转 GIF」钉在页面最底部很丑；③ 「自定义参数」内联卡片
一展开就把动图卡片区挤没。本次按用户提的痛点重构，只动 `pages/gif_page.py`（内核、队列、其它页面零改动）。

**根因（实测数据）**：`items_scroll` 是页面布局里**唯一**带 `stretch=1` 的项，但初始被
`setVisible(False)`。QBoxLayout 分配时**跳过隐藏项**，此时全布局没有一个可见伸缩项 →
多出来的垂直空白被**平均分摊给所有可见项**（标题/说明/表单被推开、空隙撑大，就是"一进去很空"的样子）；
解析成功后滚动区变可见并吃掉全部空白 → 上方内容瞬间弹回顶部。离屏实测三种状态的 y 坐标：

| 状态 | 链接输入框 y | 下载按钮 y |
|---|---|---|
| 进入页面 | 355 | 549 |
| 解析出 3 张卡片 | **89**（上移 266px） | 613 |
| 清空 / 重新解析 | 355（又弹回） | 549 |

**版式（新的固定骨架）**：标题 → 说明 → 参数卡（链接·输出目录·编码质量）→ 选择区操作行
（计数·全选·下载）→ 展示区 → 日志间距。**只有展示区是伸缩项**。

- **展示区 = 「空态占位 / 卡片网格」二选一的 `QStackedWidget`**（`GifPage._show_cards()` 切页）。
  两页都在同一个槽位、切换不改几何，故解析前后**整页零位移**（实测解析前/解析后/自定义参数生效/
  取消/清空等状态的 y 与高度逐项相同）。空态是"图标 +「还没有解析动图」+「请粘贴 X 动图链接并
  解析」"的居中占位（两行同为 `BodyLabel` 字号），不是白板，也不是常驻可见的空 `ScrollArea`。
- **「下载并转 GIF」不再钉在页面最底**：与「全选/全不选」、计数文案同放在**选择区操作行**——
  全选键原先挤在链接栏旁边（与"选中"语义不在一处），本次一并对齐。
- **空态/网格切换用两页而不是"隐藏网格"**：隐藏项不参与分配，回到上面那条根因。

**自定义参数改浮层（`_CustomParamsView` + `qfw.Flyout`）**：内联卡片展开会挤掉卡片区，改为在质量
下拉上弹 `Flyout`（原生 `FlyoutViewBase` 子类，自带圆角/阴影/点空白即关），完全不占页面布局。
浮层宽 400px（2026-10-13 用户要求加宽）。
- **浮层里没有「确定/取消」按钮：关闭（点框外任意位置）= 确定**，提示语写明这一点。
- **宽度 / 帧率上限默认留空**（占位文案标注"必填"），色数与 dither 保留默认（128 / none）。
  不预填 480/30——那是编造的默认值，会让用户以为不填就按它编码。已有已确认参数时预填（便于微调、
  也保证"原样关掉"是无操作）。
- **关闭时的取舍**：参数填全 → 提交；没填全 → 不提交。此时若**已提交过**自定义参数（`_committed_
  quality_index == _CUSTOM_INDEX`）就沿用旧参数不动；否则回退到上一个预设档并弹 InfoBar 说明
  原因——避免下拉"莫名跳回去"（实测这条路径下不当心就会把档位静默改掉）。
- **入口是「调整参数」按钮（`qfw.PushButton`；2026-10-19 前用 `TransparentPushButton`，随全站按钮口径统一
  改为标准次要按钮），且只在「自定义…」档出现**，与参数摘要
  （`640px · 20fps · 32 色 · sierra2_4a`）一起显隐。浮层点空白处即关，没有这个按钮就只能反复切
  档位回来才能重开（2026-10-13 用户口径：入口要按钮 + 仅自定义档出现；当时指定文字按钮，
  2026-10-19 改为标准 `PushButton`）。
- **质量行必须装在定高容器里**（`quality_row.setFixedHeight(max(下拉, 按钮的 sizeHint))`）：
  按需显隐会让行高在 27↔32px 之间跳，**把下面整块推动 5px**（实测：先做成"常驻占位"也是为这个；
  定高容器是同一目的的更干净解法，且支持"仅自定义档出现"）。换用 `PushButton` 后按钮 sizeHint
  变高（含边框/内边距），定高容器取的是 max，行高仍由容器钉死、不随显隐变化。
- **确认口径 = 「已提交档位」**：预设档点选即提交；「自定义…」只有浮层点「确定」才提交。
  浮层被取消/点空白处关闭 → 回退到 `_committed_quality_index`。**是否确认记在浮层实例上**
  （`flyout.confirmed`），不放页面级标志——页面级标志在"确认后未经浮层关闭路径"时会残留，
  实测会让下一次取消不回退档位（真实踩到）。
- 切回预设档**不清空** `_custom_params`（下次打开浮层用它预填）；非自定义态下它不参与入队。

**动图卡片视觉对齐「已完成」页面**（`CompletedThumbnailCard` + `CoverAreaWidget`）：
无卡片底色、16:9 圆角(8)封面（仍用 `RoundedCoverWidget`，与已完成页封面同款渲染）、封面下文字。
选中态**不再画主题色描边（原绿框）**，也不叠任何遮罩（2026-10-13 用户要求去掉主题色遮罩——
遮罩盖在动图上影响看清画面），只有**右上角主题色圆底 + 白色对勾（自绘路径，不依赖图标资源；
圆底带 1px 半透明白描边，浅色/同色系封面上也能和背景分开）+
标题转主题色**；悬停时封面轻微变暗（alpha 40，与已完成页悬停同款反馈）。卡片 200 → 240px 宽。

- **反馈必须画在封面控件自身（`_GifCover(RoundedCoverWidget)`）**：QWidget 的绘制顺序是
  "父控件先、子控件后"，画在卡片 `paintEvent` 里的蒙版会被整块封面盖掉（实测完全看不到选中反馈）。
  悬停态由卡片在 `enterEvent/leaveEvent` 推给封面（封面设了
  `WA_TransparentForMouseEvents` 让点击穿透到卡片，自身收不到鼠标事件）。
- 卡片仍须 `setFixedSize`（`AdaptiveFlowLayout` 只用 `sizeHint().height()` 定高，见决策 30）。

**易用性**：链接框/输出目录框开 `setClearButtonEnabled`；链接框回车即解析；解析/下载/空态按钮带
`FluentIcon`；网格区接 `set_smooth_scroll_params`（与任务队列页同款平滑滚动）。

**验证（2026-10-13 离线冒烟，`QT_QPA_PLATFORM=offscreen`，全程不触网）**：44 项断言全通过——
浮层形态（宽 400 / 无按钮 / 宽度帧率默认空 / 色数 dither 默认值 / 缺项拒绝）、空态两行文案
（文本 + 同字号）、解析/勾选联动/全选文案/按钮可用性、**五种状态垂直几何逐项一致**
（含"仅自定义档出现"的摘要与「调整参数」）、浮层四条关闭路径（空手关闭→回退预设且不落参数、
填全关闭→提交、从按钮重开→预填且原样关闭为无操作、编辑时清空必填→沿用旧参数保持自定义档）、
入队 `args`（6 个位置参数、`quality=GifQuality.CUSTOM`、`custom_params`）与
`kwargs={'selected_indexes': [1, 3]}`、清空回空态、无动图分支；UTF-8 与 GBK（`PYTHONUTF8=0`）
环境各跑一遍，退出码 0。另用离屏渲染出 PNG 肉眼复核了浮层（空/预填）、空态、卡片
（选中只有对勾、悬停变暗）、自定义档摘要与按钮。

**已知取舍**：① 摘要文案长度会左右移动它右侧的「调整参数」按钮（两者同一行，不影响垂直版式）；
② 网格区行数超过视口时最后一行会被裁一半（正常滚动行为，视口约 380px 只容得下 2 行 168px 卡片 + 间距）。

# 决策 54. 嗅探页表格视图右侧与默认视图统一：表格铺满到窗口右缘，内容留白由列宽让出（2026-10-20）

## 背景

决策 49 把主布局的 20px 右外距去掉，让默认视图的滚动条贴到窗口右缘。当时
`table_view` 为了「表格右边缘与改动前一致」，在容器上补了 24px 右内距 —— 于是
两个视图的右端出现了不一致：

| | 内容右缘 → 窗口右缘 | 滚动条手柄 → 窗口右缘 |
|---|---|---|
| 默认视图 | 卡片 25px | **4px**（浮在窗口右缘） |
| 表格视图（改前） | 表格 24px | **28px**（缩在表格内部） |

切视图时右侧滚动条会左右跳 24px，用户要求「表格视图的右端也采取与默认视图统一的做法」。

## 根因

qfw 的滚动条不是布局成员，而是 `QAbstractScrollArea` 的子控件，位置由
`ScrollBar._adjustPos(size)` 按**控件自身宽度**算：

```python
# qfluentwidgets/components/widgets/scroll_bar.py
self.resize(12, size.height() - 2)
self.move(size.width() - 13, 1)
```

所以「滚动条贴窗口右缘」等价于「让表格自身铺满到窗口右缘」。表格停在距窗右
24px 处，它的滚动条就永远距窗右 24 + 4 = 28px。

## 结论

**表格容器去掉右内距（铺满到窗口右缘），内容右侧 24px 的留白改由列宽分配让出。**

```python
# 容器：右内距 24 → 0，表格因此延伸到窗口右缘，滚动条随之贴边
table_layout.setContentsMargins(0, 0, 0, 0)

class _FormatTable(qfw.TableWidget):
    RIGHT_RESERVE = 24   # = SCROLLBAR_RESERVE(13) + 11，与 OPTION_MARGIN_RIGHT 同口径
    def _distribute_columns(self):
        avail = max(self.viewport().width() - self.RIGHT_RESERVE,
                    self.COL_MIN * len(self.COL_FACTORS))
        ...
```

即：视口右侧留出一整条 24px 空白，13px 让 qfw 滚动条浮在上面、余 11px 作为
「内容到滚动条」的呼吸空间，与默认视图卡片右边距是同一个口径（决策 53 的
`OPTION_MARGIN_RIGHT`）。

## 否决的方案

| 方案 | 实测结果 | 否决原因 |
|---|---|---|
| 只把 `table_layout` 右距改 0，不补列宽 | 表格贴到右缘、滚动条贴边，但**内容也顶到右缘**，滚动条压在最后一列上 | 内容被遮挡 |
| `format_table.setViewportMargins(0, 0, 24, 0)` | **完全无效**：`vp_w` 一点没变（554→578→578），列宽也不受影响 | `QTableView` 内部每次 resize 都会重置 viewport 几何，外部设置被覆盖 |
| 用 `QSpacerItem` 在容器右侧撑 24px，表格再铺满 | 与「只改右距」等价，最终表格又变窄、滚动条又缩回去 | 白改 |

## 风险

1. **`RIGHT_RESERVE` 与 `OPTION_MARGIN_RIGHT` 必须同步**：两者都是「让开滚动条
   13px + 11px 呼吸」，任一改动都要同时改另一处，否则两个视图右端又对不齐。
2. **最后一列会窄 24px**：5 列按 `COL_FACTORS` 比例分配，1920 宽下最后一列比改前
   窄约 4px（总宽 -24 摊到 5 列），内容不会截断但列宽有细微变化。
3. **表格列宽仍随滚动条显隐变化**：这是表格的既有行为（`avail` 一直取自
   `viewport().width()`），本决策没有改变它 —— 与默认视图「卡片宽度恒定不跳」
   （决策 53）不同。实测内容右缘稳定（无滚动条 25px、有滚动条 24px），但如果
   以后要消除列宽跳动，正确方向是让表格滚动条常驻，而不是动 `RIGHT_RESERVE`。
4. **`COL_MIN * 5` 兜底**：窗口极窄时 `viewport - 24` 可能小于 5 列最小宽之和，
   此时会横向溢出并出现横向滚动条。窗口最小宽 966px 时 `avail` 约 456px，远大于
   `50*5=250`，实际不会触发。
